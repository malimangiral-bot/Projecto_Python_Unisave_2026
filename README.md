# Projecto_Python_Unisave_2026
Este projecto é uma agenda de consultas online desenvolvida em python com programação orientada, permite marcar consultas online e lembretes das próximas datas e guardar o histórico de consultas já realizadas. Resolve o problema do esquecimento de consultas e da falta de registo organizado, ajudando a manter o acompanhamento dos utilizadores.
